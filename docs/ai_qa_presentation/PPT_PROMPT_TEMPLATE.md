# PPT 작성 지시문 템플릿

## 목적
사내 발표용 PPT를 **발표자가 바로 쓰는 완성형 초안** 수준으로 산출하기 위한 재사용 지시문. 단순 요약이 아니라 제목·본문 불릿·발표자 노트 3종 + 증거 기반 시각화 + 검증 보고까지 포함한 결과물을 기본선으로 한다.

## 사용법
- 새 PPT 요청 시 아래 **long** 또는 **short** 템플릿을 복붙하고, **발표 주제·핵심 메시지만 갈아끼운다.**
- 결과물은 `.pptx` + 재생성용 `gen_ppt.py`를 함께 남긴다 (working-tree 저장, 커밋은 별도 명시 승인).
- 기존 파일이 열려 잠겨 있으면 덮어쓰지 말고 `_v2`/`_v3`로 저장한다.

## 적용 기준 (요지)
- 10~15장 / 한 장 = 메시지 1개 / 16:9
- 첫 1~2장에 핵심 메시지 먼저 → 중간은 "문제 → 접근 → 실제 증거 → 결과"
- 증거 슬라이드 최소 3장, 실제 파일·로그·엑셀·JSON·YAML·이미지에서 시각화
- 숫자는 출처 확인된 것만, 불확실하면 `▣ / ▣` placeholder
- "좋아 보이는 주장"보다 **"틀린 결론을 막은 순간"** 강조
- 생성 후 슬라이드 수·노트·표/이미지/코드·로그블록 무결·placeholder를 검증해 보고

## 참조 예시 (이 기준의 기준 사례)
- 완성본: `docs/ai_qa_presentation/AI_QA_발표_2026-06-04_v2.pptx` (15장, 증거 5장 E1~E5)
- 생성기: `docs/ai_qa_presentation/gen_ppt.py`

## Long 템플릿

```markdown
사내 발표용 PPT를 작성해줘.

목표는 단순 요약이 아니라, 발표자가 바로 사용할 수 있는 완성형 초안이다.
슬라이드는 10~15장 범위로 구성하고, 각 장에는 반드시 다음을 포함한다.

1. 슬라이드 제목
2. 슬라이드 본문 불릿
3. 발표자 노트 / 발표 대본
4. 필요한 경우 표, 코드블록, 로그블록, before/after 비교, 이미지 자리
5. 숫자나 근거는 출처가 확인된 것만 사용하고, 최신값이 불확실하면 `▣ / ▣` placeholder로 남긴다

구성 원칙:
- 첫 1~2장은 핵심 메시지를 먼저 제시한다.
- 중간은 "문제 → 접근 → 실제 증거 → 결과" 흐름으로 구성한다.
- 기술 디테일은 본문에 과하게 넣지 말고, 청중이 이해할 수 있는 판단 포인트 중심으로 쓴다.
- 발표의 핵심 문장은 반복 가능하게 짧게 만든다.
- 증거 슬라이드는 최소 3장 이상 포함한다.
- 가능하면 실제 파일/로그/엑셀/JSON/YAML/이미지에서 가져온 근거를 시각화한다.
- "좋아 보이는 주장"보다 "틀린 결론을 막은 순간"을 강조한다.

디자인/형식:
- 16:9 와이드 기준
- 한 장당 메시지는 1개
- 본문은 짧은 불릿 중심
- 표는 색상으로 판정 구분: 정상/완화/FAIL/주의
- 코드·로그는 monospace 스타일로 구분
- before/after는 좌우 비교로 배치
- 결론 슬라이드는 신뢰 장치와 최종 메시지를 크게 배치

PPT 파일 생성 시:
- 결과 파일과 생성 스크립트를 함께 남긴다.
- 예: `docs/ai_qa_presentation/발표명_YYYY-MM-DD.pptx`
- 예: `docs/ai_qa_presentation/gen_ppt.py`
- 기존 PPT가 열려 있어 잠겨 있으면 `_v2`, `_v3`처럼 새 파일명으로 저장한다.
- 원본을 임의 삭제하거나 덮어쓰지 않는다.

검증 기준:
- 슬라이드 수 확인
- 모든 슬라이드에 발표자 노트가 있는지 확인
- 표/이미지/코드블록/로그블록이 깨지지 않았는지 확인
- placeholder가 의도한 것만 남았는지 확인
- PowerPoint에서 열 수 있는 파일인지 확인
- 검증 결과를 마지막에 요약한다

출력은 다음 순서로 제공한다.

1. PPT 구성 요약
2. 생성된 파일 경로
3. 슬라이드 목록
4. 추가된 증거/시각자료 목록
5. 남은 placeholder 또는 확인 필요 사항
6. 다음 선택지
```

## Short 템플릿

```markdown
이번 발표자료처럼 10~15장 PPT 완성본으로 만들어줘.
각 슬라이드는 제목·본문 불릿·발표자 노트를 포함하고, 실제 증거 기반 표/코드블록/로그블록/before-after 시각화를 넣어줘.
숫자는 확인된 것만 쓰고 불확실하면 `▣ / ▣`로 남겨.
결과물은 `.pptx`와 재생성용 `gen_ppt.py`를 함께 저장하고, 생성 후 슬라이드 수·노트 수·이미지/표 포함 여부를 검증해서 보고해줘.
기존 파일이 잠겨 있으면 덮어쓰지 말고 `_v2`로 저장해.
```
