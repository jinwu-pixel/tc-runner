### 2.3 HDF (QXDM) 미분석 사유

- Qualcomm 독점 binary format
- 일반 PDF / 텍스트 도구 적용 불가
- **다음 세션 사용자 측 QCAT post-process 필요**:
  - 0x713A UMTS UE OTA → `SM_ACTIVATE_PDP_CONTEXT_REJECT` / `sm_cause_val`
  - 0x1544 QMI_MCS_QCSI_PKT → `wds_start_network_interface` resp / `verbose.call_end_reason`
- 본 사이클에서는 HDF 존재 사실만 보존, content extraction 미수행 → `EVIDENCE_MATRIX.md` 에 NOTE

### 2.4 adb shell hang 원인 가설

| 가설 | 근거 |
|---|---|
| **QXDM 도구가 DIAG/USB 채널 점유** | 사용자 명시 "로깅 중" + adb logcat 은 동작 / adb shell 만 hang → DIAG 채널 vs ADB transport 일부 충돌 가능. QCT diag bridge 가 USB endpoint 점유 시 adb shell pty 응답 지연 사례 보고 있음. |
| **단말 측 adbd 응답 지연** | 다중 로깅 활성 시 단말 CPU 부담 → 응답 지연 가능. 그러나 `adb logcat -d -b main` 은 동작 → 부분 점유 |
| **PowerShell pipeline buffer 문제** | Start-Process 격리해도 동일 hang → 단말 측 issue 가능성 더 높음 |

**다음 세션 액션**: QXDM 캡처 종료 → adb shell sanity 재확인 → 정상 시 Phase 1 진입 (`CHECKLIST_NEXT_SESSION.md` 참조).
