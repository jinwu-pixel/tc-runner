## 1. 수정 내용 (코드 레벨, logcat 원문)

런처 카운트 쿼리가 **null-safe 술어로 변경**됨:

| | SQL (logcat `getUnreadMissedCallCount Query String`) |
|---|---|
| 수정 前 `MZ0116` | `SELECT _id, type, is_read FROM calls WHERE type = ? AND **is_read = ?** ORDER BY date DESC` |
| 수정 後 `DZ0721` | `SELECT _id, type, is_read FROM calls WHERE type = ? AND **is_read is not ?** ORDER BY date DESC` |

심플(미러) 측 쿼리는 변경 없음(원래 `IS NOT 1`). → **노말을 미러에 맞춰 정합**한 방향으로,
2026-07-16에 개발자에게 문의 형식으로 제안한 타깃(`is_read = 0` → `is_read IS NOT 1`)과 일치.

빌드만 바뀐 완전 통제 대조.

## 6. 측정 함정 (본 세션 실측, 재사용)

- **PowerShell에서 다중 토큰 `--where "type=3 AND is_read=0"` 은 인용부호가 소실되어 조용히 0을 반환.**
  단일 토큰(`type=3`)은 통과 → 부분 성공이 오판을 부름. 다중 조건은 **Bash 도구 경유** 또는 전 행 덤프 호스트측 파싱.
- **`adb exec-out screencap -p > file` 을 PowerShell로 리다이렉트하면 BOM이 섞여 PNG가 깨짐.** Bash 경유 필요.
- 좌표 탭은 화면 상태 확인 없이 연속 실행 금지 — 키패드 화면이 탭바를 덮어 두 번째 탭이 빗나가
  한 사이클 측정이 무효화됨(스크린샷으로 검증 후 정정). 탭 사이 **스크린샷 확인 필수**.
- 카운터 로그는 이벤트 발생 시에만 출력 → 유휴 `logcat -d` 에는 없음.
