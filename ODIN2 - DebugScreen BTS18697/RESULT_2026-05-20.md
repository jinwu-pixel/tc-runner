## WCDMA 측 IMS 가능성 확인 (개발자 보고 보조)

WCDMA에서 IMS 표시가 valid한 요구인지 의문이 있을 수 있어 별도 검증:

| Layer | WCDMA에서 가능? | 본 단말 실측 |
|---|---|---|
| IMS PDN (PS bearer) | ✓ 3GPP Rel-5+ 표준 가능 | ✓ rmnet_data2 활성 |
| IMS IP 할당 | ✓ | ✓ `2001:2d8:6e49:1962:886c:dbff:fe77:3af` |
| P-CSCF 수신 | ✓ | ✓ 3건 수신 |
| MMTEL capability | ✓ | ✓ |
| VoLTE식 음성 IMS 등록 | △ carrier 정책 | ✗ (SKT WCDMA는 `carrier_volte_available_bool=false`, 음성은 CS) |

= **PDN/IP layer에선 IMS가 명백히 활성. 표시할 IP가 시스템에 존재.** 음성 IMS는 carrier가 비활성이지만 RCS/메시지/관리 목적으로 IMS PDN은 유지됨. PDF 보고자(Sh hwang) 의도("IMS 연결 시 표시")와 정합.
